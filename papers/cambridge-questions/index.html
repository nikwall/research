The Cambridge Questions: Critical Uncertainties for the Economy and for Economics

Niklas Wallmeier

In preparation. The first conversations with scholars are still to come.

Project page on nikwall.deAsk about this project

In short

What are the most crucial open questions for the economy and for economics as a field? I name my own five uncertainties for each, then I will ask scholars at Harvard and MIT to name theirs, one to one. From these lists one set of questions takes shape, worded together.

How a conversation runs

  • Name: five uncertainties for each list, before seeing anyone else's.
  • Open up: for each one, the two ends of what could happen.
  • Compare: the set so far appears, with overlaps marked.
  • Word: reword, merge or add together. The set moves on to the next conversation.
  • Pass on: whose view would change this set most?

What it will produce

  • One shared set of questions, worded together, which every scholar reads once and can comment on.
  • Two maps, one for the economy and one for economics as a field, each spanned by the two uncertainties that matter most and move independently of each other.
  • As a second stage, signals for each axis: forecast questions with a date and a clear criterion.
